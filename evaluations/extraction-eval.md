# Extraction evaluation — pipeline output vs golden reference set

**Method.** `evaluations/golden_rules.json` is a hand-curated reference ruleset produced
independently (Claude Opus, human-in-the-loop, full-document review) — it was NOT generated by
this repo's pipeline. We score the pipeline's `data/rules.json` against it: every golden rule
should be represented (recall); pipeline rules outside golden's scope are acceptable unless
hallucinated (precision). Golden's own scope note declares consumer support, vulnerable-consumer
chapters, 1:1 interactions and distribution-chain duties deliberately out of its scope.

## Round 1 — initial pipeline output (subset = Ch 4/5/8/9/10 + PRIN 2A.5 pp.127–131)

**Recall: 12/13 (92%).** Mapping:

| Golden rule | Pipeline rule(s) | Covered |
|---|---|---|
| CP-01 good outcomes | CP-01 | ✓ |
| CC-01 good faith | CC-01 | ✓ |
| CC-02 foreseeable harm | CC-02 | ✓ |
| CC-03 enable objectives | CC-03 | ✓ |
| **CC-04 no exploiting emotions/biases (urgency, FOMO)** | — (red-flag under CC-02 only) | **✗ MISS** |
| CU-01 clear/fair/not misleading | CU-04 | ✓ |
| CU-02 support understanding | CU-01+CU-02+CU-03 | ✓ (finer split) |
| CU-03 risk/benefit balance | CU-08 + CU-04 red flags | ✓ |
| CU-04 plain language | CU-07 | ✓ |
| CU-05 prominence / disclaimers | CU-08 + CU-09 | ✓ |
| CU-06 appropriate detail | CU-10 | ✓ |
| CU-07 in good time | CU-03 (timeliness limb) | ✓ |
| CU-08 tailoring | CU-11+CU-12+CU-13 | ✓ |

**Root cause of the miss (verified, not assumed):** the behavioural-exploitation obligations
live in the legal instrument at PRIN 2A.2.3G(b)–(c) / 2A.2.10G(2), PDF pp.108–109 — pages the
subset did not include (only PRIN 2A.5, pp.127–131, was operator-added). Ch 5 prose mentions
biases only in passing. The extractor cannot extract text it never saw: a **subset coverage
gap, not an extraction-quality failure**. The miss mattered: CC-04 is the rule that catches the
brief's canonical "get rich tomorrow 🚀🚀🚀" case on urgency/excitement grounds.

**Precision:** no hallucinated rules — all 31 trace to real document text. Three rules
(CU-15/16 one-to-one interactions, CU-17 distribution chain) fall in golden's declared
process-flavoured exclusions; CS-*/VC-* rules are outside golden's scope but valid extractions
from chapters the planner scoped in.

## Fix

Extend the operator-added made-rules range to include Principle 12 + PRIN 2A.1–2A.2:

```
npm run cut -- \
  --extra "Appendix 1 / Principle 12 and PRIN 2A.1–2A.2 cross-cutting obligations — made rules:104-110" \
  --extra "Appendix 1 / PRIN 2A.5 Consumer understanding — made rules:127-131"
npm run extract
```

## Round 2 — after fix (subset ~14.5k words)

**Recall: 13/13 (100%).** The previously missed obligation now extracts as two standalone
high/medium rules: CC-02 ("must not manipulate or exploit customers' emotions, behavioural
biases or vulnerabilities to create demand or mislead") and CC-04 (exploiting inertia /
over-optimism causing foreseeable harm). The wider made-rules context also produced CC-05
("must not imply the risks do not exist") and CU-13 ("disclosure as a shield") — both strong,
text-checkable additions.

Notes from round 2:
- Re-extraction is non-deterministic: the rule inventory reshuffled (31 → 31 rules but
  different splits; e.g. golden CC-03 "enable objectives" is now covered via CU-01/CU-03
  rather than a standalone cross-cutting rule). Coverage of golden is complete; granularity
  differs run to run.
- Three process-leaning rules appeared (CU-11 testing, CU-12 adapt-on-evidence, CC-07 redress)
  that golden scopes out. Kept: they mostly return `not_applicable` for a static marketing
  text and cost little; a stricter extractor instruction is a possible refinement.

## Findings about the golden set itself

Golden is well-constructed as a baseline (declared scope, binding-source citations, checkable
phrasing), with three findings:

1. **Gap:** golden CU-08 lists the audience/complexity/channel limbs of PRIN 2A.5.8R but omits
   the fourth limb — tailoring to **the firm's role** (advice vs information-only boundary).
   Text-checkable and highly relevant for a trading platform ("we tell you exactly what to
   buy" from an execution-only broker). The pipeline extracted it in both rounds (round 1
   CU-14, round 2 CC-08).
2. Golden CC-02's `check` has inverted polarity ("Could this… lead to harm?" — YES = breach),
   the same slip our round-1 extraction made in its CC-02. Two different models, identical
   polarity error on the foreseeable-harm rule.
3. Minor citation drift: golden places PRIN 2A.5.3R at "PDF p.126"; the 2A.5 text begins at
   p.127 (verified by content probe).

## Takeaway

The extractor itself is strong (92% recall on first sight of the text, 100% after the subset
gap was closed; zero hallucinations; both rounds caught a real gap in the human-curated golden
set). The dominant quality lever is **subset coverage** — which pages the LLM gets to see —
not extraction prompting. That is where evaluation effort should go for new documents.
